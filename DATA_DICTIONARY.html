Data Dictionary — Event & Survey Platform

**แหล่งอ้างอิง**`database-schema.dbml`
**เวอร์ชันอ้างอิง**SRS Draft v2.1.0 — 22 ตุลาคม 2026
**ฐานข้อมูลเป้าหมาย**PostgreSQL (production) / json-server mock (`db.json`)
**ภาษาเอกสาร**ไทย

สัญลักษณ์คอลัมน์ “Key”

สัญลักษณ์ความหมาย
**PK**Primary Key
**FK**Foreign Key (อ้างอิงตารางอื่น)
**UK**Unique / Unique composite
**NN**Not Null (บังคับใส่ค่า)

ภาพรวมความสัมพันธ์หลัก

users ──► platform_roles / roles
events ──► event_translations, event_form_settings, event_banners, whitelist_entries
events ──► forms ──► form_fields ──► field_options
forms ──► form_submissions ──► submission_answers ──► answer_option_selections
form_submissions ──► registrations ──► whitelist_entries
events ──► dashboard_layouts ──► dashboard_widgets

เส้นทางข้อมูลผู้เข้าร่วม: forms → form_submissions → submission_answers → answer_option_selections (ลงทะเบียนมีแถว registrations เพิ่ม)

0) Enum / ค่าคงที่

`system_role`

ค่าความหมาย
`platform_admin`ผู้ดูแลแพลตฟอร์ม
`event_user`ผู้ใช้ในอีเวนต์ (มี role ภายในอีเวนต์)

`permission_code` (สิทธิ์ระดับอีเวนต์)

ค่าความหมาย
`manage_dashboard`จัดการ Dashboard
`manage_event`จัดการข้อมูลอีเวนต์
`manage_registration_form`จัดการฟอร์มลงทะเบียน
`manage_survey_form`จัดการแบบสอบถาม
`manage_sub_user`สร้าง/มอบ Role ให้ผู้ใช้ในอีเวนต์

`platform_permission_code` (สิทธิ์ระดับแพลตฟอร์ม)

ค่าความหมาย
`manage_platform_users`จัดการผู้ใช้แพลตฟอร์ม
`manage_all_events`จัดการอีเวนต์ทั้งหมด
`view_platform_overview`ดูภาพรวมแพลตฟอร์ม
`impersonate_event_user`สวมสิทธิ์เข้าใช้งานในฐานะ Event User

`account_status`

ค่าความหมาย
`invited`เชิญแล้ว ยังไม่ตั้งรหัสผ่าน/เข้าระบบ
`active`ใช้งานได้
`suspended`ระงับชั่วคราว
`removed`ลบบัญชีแล้ว (คง id ไว้)

`event_status`

ค่าความหมาย
`draft`ร่าง
`scheduled`ตั้งเวลาไว้
`open`เปิดใช้งาน
`closed`ปิดแล้ว (หยุดลงทะเบียน)

`survey_access`

ค่าความหมาย
`public`ใครก็ตอบแบบสอบถามได้
`registered_only`ต้องลงทะเบียนก่อน

`form_type` / `form_status`

Enumค่าความหมาย
`form_type``registration`ฟอร์มลงทะเบียน
`form_type``survey`แบบสอบถาม
`form_status``draft` / `scheduled` / `open` / `closed`สถานะวงจรชีวิตฟอร์ม

`field_type`

ค่าความหมาย
`short_text`ข้อความสั้น
`long_text`ข้อความยาว
`single_choice`เลือกได้หนึ่งข้อ
`multiple_choice`เลือกได้หลายข้อ
`dropdown`รายการแบบเลื่อน
`date` / `time` / `number` / `email`ตามชนิด
`rating`ให้คะแนน (ไอคอนหรือสเกล)

`rating_display` / `rating_icon`

Enumค่าความหมาย
`rating_display``icon`แสดงเป็นดาว/หัวใจ/ไลก์
`rating_display``linear_scale`สเกลตัวเลข + ป้ายปลายสเกล
`rating_icon``star` / `heart` / `like`ชุดไอคอนเมื่อเป็นโหมด icon

`submission_status` / `whitelist_entry_status`

Enumค่าความหมาย
`submission_status``submitted`ส่งแล้ว (นับความจุ)
`submission_status``cancelled`ยกเลิกแล้ว (คืนที่นั่ง)
`whitelist_entry_status``available`ยังไม่ใช้โค้ดลงทะเบียน
`whitelist_entry_status``joined`ใช้โค้ดลงทะเบียนแล้ว

Dashboard enums

Enumค่าความหมาย
`dashboard_widget_type``number`ตัวเลขเดี่ยว
`comparison`ตัวเลขเทียบกับช่วงก่อน/เป้า/ความจุ
`chart`กราฟ
`dashboard_aggregation``count` / `sum` / `average` / `minimum` / `maximum` / `percentage`วิธีสรุป
`dashboard_chart_type``bar` / `line` / `pie` / `donut`ชนิดกราฟ
`dashboard_comparison_mode``previous_period`เทียบช่วงก่อน
`target`เทียบเป้า (`target_value`)
`capacity`เทียบที่นั่งจาก `event_form_settings`
`display_size``small` = 1×1, `medium` = 2×2, `large` = 3×3, `custom` = ใช้ `grid_w`/`grid_h`ขนาด widget
`text_align``left` / `center` / `right`จัดข้อความ
`date_type``day` / `week` / `month` / `three_months`ช่วงวันที่ของ widget

1) สิทธิ์และบัญชี

`users` — บัญชีผู้ดูแล (ผู้เข้าร่วมไม่มีบัญชี)

FieldTypeKeyความหมาย
`id`uuidPKรหัสผู้ใช้
`email`varchar(320)UKอีเมลล็อกอิน (ตั้ง null เมื่อ removed)
`password`varchar(255)NNรหัสผ่าน (mock/demo)
`display_name`varchar(160)NNชื่อที่แสดง
`system_role`system_roleNN`platform_admin` หรือ `event_user`
`platform_role_id`uuidFK → platform_rolesใช้เฉพาะ platform_admin
`event_id`uuidFK → eventsใช้เฉพาะ event_user (สังกัดอีเวนต์เดียว)
`role_id`uuidFK → rolesCustom Role ในอีเวนต์
`role_assigned_by_user_id`uuidFK → usersผู้มอบ Role
`role_assigned_at`timestamptzเวลามอบ Role
`status`account_statusNNสถานะบัญชี
`invited_by_user_id`uuidFK → usersผู้เชิญ
`joined_at`timestamptzเวลาเข้าระบบครั้งแรก
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้
`removed_at`timestamptzเวลาลบบัญชี

กฎ: platform_admin → มี platform_role_id, event_id/role_id เป็น null event_user → มี event_id+role_id, platform_role_id เป็น null

`platform_roles` — Role ระดับแพลตฟอร์ม

FieldTypeKeyความหมาย
`id`uuidPKรหัส Role
`name`varchar(160)UK, NNชื่อ Role
`description`textคำอธิบาย
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้
`created_by` / `updated_by`uuidFK → usersผู้สร้าง/ผู้แก้
`deleted_at`timestamptzsoft delete

`platform_role_permissions`

FieldTypeKeyความหมาย
`id`uuidPKรหัสแถว
`platform_role_id`uuidFK, UK(ร่วม)Role แม่
`permission`platform_permission_codeNN, UK(ร่วม)สิทธิ์หนึ่งรายการ

`roles` — Custom Role ในอีเวนต์

FieldTypeKeyความหมาย
`id`uuidPKรหัส Role
`event_id`uuidFK, UK(ร่วม name)อีเวนต์เจ้าของ Role
`name`varchar(160)NN, UK(ร่วม)ชื่อ Role ในอีเวนต์
`description`textคำอธิบาย
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้
`created_by` / `updated_by`uuidFK → users, NNผู้สร้าง/ผู้แก้
`deleted_at`timestamptzsoft delete

`role_permissions`

FieldTypeKeyความหมาย
`id`uuidPKรหัสแถว
`role_id`uuidFK, UK(ร่วม)Event Role
`permission`permission_codeNN, UK(ร่วม)สิทธิ์หนึ่งรายการ

2) อีเวนต์และเนื้อหา

`events`

FieldTypeKeyความหมาย
`id`uuidPKรหัสอีเวนต์
`slug`varchar(160)UK, NNURL slug (แก้ไม่ได้หลัง publish)
`status`event_statusNNสถานะอีเวนต์
`default_locale`varchar(35)NNภาษาเนื้อหาเริ่มต้น (เช่น `th`)
`start_at` / `end_at`timestamptzวัน–เวลาเริ่ม/จบงาน
`is_private`booleanNNอีเวนต์ส่วนตัว (บังคับลงทะเบียน+whitelist)
`has_registration`booleanNNเปิดฟอร์มลงทะเบียน
`has_survey`booleanNNเปิดแบบสอบถาม
`survey_access`survey_accessใครตอบแบบสอบถามได้ (null ถ้าไม่มี survey)
`opens_at` / `closes_at`timestamptzช่วงเปิดรับโดยรวมของอีเวนต์
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้
`created_by` / `updated_by`uuidFK → users, NNผู้สร้าง/ผู้แก้

กฎสำคัญ - is_private = true → ต้อง has_registration = true + มี whitelist_entries - survey_access = registered_only → ต้อง has_registration = true - ความจุไม่เก็บที่นี่ → ดู event_form_settings

`event_translations` — เนื้อหาหลายภาษา

FieldTypeKeyความหมาย
`id`uuidPKรหัสแถว
`event_id`uuidFK, UK(ร่วม locale)อีเวนต์แม่
`locale_code`varchar(5)NN, UK(ร่วม)รหัสภาษา เช่น `th`, `en`
`display_order`intNN, UK(ร่วม event)ลำดับภาษา
`title`varchar(240)NNชื่องาน
`description`textรายละเอียด
`location_name`varchar(240)ชื่อสถานที่
`address_text`textที่อยู่
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้

`event_form_settings` — ความจุต่อโฟลว์ (ตั้งตอนสร้างอีเวนต์)

FieldTypeKeyความหมาย
`id`uuidPKรหัสแถว
`event_id`uuidFK, UK(ร่วม form_type)อีเวนต์
`form_type`form_typeNN, UK(ร่วม)`registration` หรือ `survey`
`is_unlimited`booleanNNtrue = ไม่จำกัดที่นั่ง
`capacity`intจำนวนที่นั่ง (null ถ้า unlimited)
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้

การนับที่นั่ง: นับ form_submissions ที่ status = submitted ของฟอร์มชนิดนั้น ยกเลิกคำตอบ (cancelled) = คืนที่นั่ง

`event_banners`

FieldTypeKeyความหมาย
`id`uuidPKรหัสแบนเนอร์
`event_id`uuidFK, UKอีเวนต์ (อีเวนต์ละหนึ่งแถวตาม schema ปัจจุบัน)
`banner_url`varchar(2048)NNURL รูปแบนเนอร์
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้

`form_fields`

FieldTypeKeyความหมาย
`id`uuidPKรหัสคำถาม
`form_id`uuidFKฟอร์มแม่
`type`field_typeNNชนิดคำถาม
`display_order`intNN, UK(ร่วม form)ลำดับแสดง
`is_required`booleanNNบังคับตอบ
`min_number` / `max_number`decimalขอบเขตตัวเลข / ปลายสเกล

`rating_display`rating_displayโหมด rating (null ถ้าไม่ใช่ rating)
`rating_icon`rating_iconไอคอน (เฉพาะโหมด icon)
`rating_max`intคะแนนสูงสุดโหมด icon (min = 1)
`created_at` / `updated_at`timestamptzNNเวลาสร้าง/แก้
`deleted_at`timestamptzsoft delete

`field_translations`

FieldTypeKeyความหมาย
`id`uuidPKรหัสแถว

`scale_min_label` / `scale_max_label`varchar(240)ป้ายปลายสเกล (linear_scale)

`display_order`intNN, UK(ร่วม)ลำดับ
`created_at`timestamptzNNเวลาสร้าง
`deleted_at`timestamptzsoft delete

`option_id`uuidFK, UK(ร่วม locale)ตัวเลือกแม่
`locale_code`varchar(35)NNภาษา
`label`varchar(240)NNข้อความตัวเลือก

4) ไวท์ลิสต์ (ระดับอีเวนต์)

`whitelist_entries`

FieldTypeKeyความหมาย
`id`uuidPKรหัสรายการ
`event_id`uuidFKอีเวนต์เจ้าของ (ไม่ผูกฟอร์ม)
`access_code`varchar(32)NN, UK(ร่วม event)โค้ดที่ระบบเจน ให้ผู้เข้าร่วมกรอก

`status`whitelist_entry_statusNN`available` / `joined`
`joined_at`timestamptzเวลาที่ใช้โค้ดลงทะเบียนสำเร็จ
`created_at`timestamptzNNเวลาสร้าง
`deleted_at`timestamptzsoft delete

โฟลว์: Admin เพิ่มคน → ได้ access_code → ผู้เข้าร่วมกรอกตอนลงทะเบียน → available → joined

`submission_answers`
